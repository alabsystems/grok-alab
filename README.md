# grok-alab

ALab harness that runs unmodified Grok Build from the atpkg store and moves running sessions onto newer builds.

grok-alab is made by [ALab](https://alab.systems). Its source code is not published:
this repository carries grok-alab's binary releases, their release notes, and its
license.

## Install

Install it with aterm's package manager, which verifies every signed binary:

```sh
aterm pkg install grok-alab
```

Every release is listed under [Releases](https://github.com/alabsystems/grok-alab/releases),
and its notes are in `release-notes/`.
